# The CSS Codex

A specimen atlas of the CSS language. **Every property and (almost) every value
shown is derived from the CSS EBNF grammar** — nothing is hand-written except a
small table of representative samples for the open-ended numeric / colour / string /
function leaf types. The grammar is walked, the values are rendered in a React
gallery, and every property/value pair is screenshotted in headless Chrome.

```
lang/*.ebnf ──gluon v2──▶ FileDescriptorProto ──proto reflection (cmd/gen)──▶
  property → value[]  ──▶  gallery/ (React)  ──screenshot──▶  chromerpc  ──▶  screenshots/
```

`cmd/gen` walks the compiled grammar by proto reflection: alternation → union of
variants, sequence → product of fields, keyword → its literal, open-ended **leaf**
(`<length>`, `<number>`, `<color>`, `<string>`, OpenType tags, …) → samples from
`cmd/gen/reps.go`. Every composite above a leaf (colours, gradients, shapes,
`calc()`, functions) is walked structurally — no shortcuts. Properties that only
mean something in motion or on interaction get live demonstrators
(`gallery/live.jsx`, `gallery/demos2.jsx`) captured as temporal GIFs; paged-media
props are printed to PDF and rasterised.

## Run

```sh
./LET_IT_RIP.sh        # setup → generate → screenshot → serve (full pipeline)
```

| Script | What |
|---|---|
| `./gen.sh` | walk the grammar → `generated/` data + assemble the deployable `dist/` bundle |
| `./shoot.sh` | headless chromerpc → `screenshots/` (PNGs, GIFs, paged PDFs) |
| `./serve.sh` | serve the self-contained `dist/` bundle + open it |
| `./deploy.sh` · `./validate-deploy.sh` | publish `dist/` to Cloudflare Pages, then drive a live user journey → `journey.gif` ([`DEPLOY.md`](DEPLOY.md)) |
| `python3 showcase.py` | regenerate the showcase below from `showcase.json` + `screenshots/` |

`ONLY="display,filter" ./shoot.sh` limits the run. chromerpc is built from
`$CHROMERPC_SRC` (default `~/Documents/chromerpc`) and cached in `/tmp/chromerpc-ct2`.

## The live demo

The gallery is a fully static site; `dist.sh` bundles it self-contained (vendored
React + Babel, grammar data, assets) for any static host. The live build is at
**[css-demo.pages.dev](https://css-demo.pages.dev)** — `validate-deploy.sh` proves
it by driving a real browser through a user journey (search → open → scroll →
grammar → copy) over the chromerpc bidi pool:

![Validated user journey on the live site](journey.gif)

## Verification

Every value of every property is judged by eye (multimodal, no byte comparison)
for **correctness** (does the render reflect the value) and **distinctness** (do
different values look different). Each property is sorted into one of the
categories in [`CATEGORIES.md`](CATEGORIES.md) — from "every value uniquely and
correctly shown" through "only distinguishable beyond the headless pipeline's
reach". That doc is the authoritative per-property verdict.
