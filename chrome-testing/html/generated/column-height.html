Column Height

column-height

Experimental / Non-standard: column-height is not part of any CSS specification. The examples below simulate the concept by constraining column container height. Browser support is effectively nonexistent.
height: auto (default)
Columns grow to fit their content naturally. The container expands as needed. Text flows across columns and the overall height adjusts automatically to accommodate all content without overflow.
auto
height: 80px
When height is constrained to 80px, column content is limited. Overflow is hidden and the columns are compact. This simulates a short column-height value restricting how tall each column can be.
80px
height: 140px
A medium height constraint gives columns more room. Text can flow across the available columns while still being bounded. This provides a balance between compactness and readability across the column layout.
140px
height: 200px
A taller height constraint allows columns to display more content vertically before wrapping. The content fills more of each column before flowing to the next. This simulates a generous column-height setting where readability is prioritized.
200px
