Column Fill

column-fill

column-fill: balance-all
Content is evenly distributed across all columns
The column-fill property controls how content is distributed across columns. With balance, the browser tries to equalize the height of content in each column. This creates a visually balanced layout where no single column is significantly taller. Notice how the text is spread evenly across all three columns in this example, creating a harmonious appearance.
column-fill: balance-all ! important
Content fills columns sequentially, one at a time
With column-fill set to auto, content fills each column sequentially. The first column is filled completely before content flows to the next. This means columns may have uneven heights. The last column may be shorter or even empty if there is not enough content. Notice how this text fills the first column fully before moving to the next, creating a sequential flow pattern.
