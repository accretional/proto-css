Column Fill

column-fill

The column-fill property controls how content is distributed across columns. With balance, the browser tries to equalize the height of content in each column. This creates a visually balanced layout where no single column is significantly taller than the others. Notice how the text is spread evenly across all three columns, creating a harmonious and symmetrical appearance. Each column ends at roughly the same vertical position.
