Column Fill

column-fill

Column fill controls how content is distributed across columns. With balance, the browser equalizes column heights so all columns are roughly the same length. With auto, content fills columns sequentially from left to right, meaning early columns are completely full while later ones may be short or even empty. This difference is most visible when there is enough content to partially fill the available column space. Here is additional text to ensure there is enough content to clearly see the difference between balanced and automatic column filling. The more text we add, the clearer the visual distinction becomes. Notice how balanced columns try to keep all columns the same height, while auto fills them one by one in order. This paragraph adds even more content so the columns have substantial text to distribute.
