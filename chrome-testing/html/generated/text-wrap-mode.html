Text Wrap Mode

text-wrap-mode

wrap
This text will wrap to the next line when it reaches the edge of the container. The browser inserts soft line breaks to keep text within bounds.
container: 300px
Text wraps to fit container
text-wrap-mode: wrap ! important Default behavior. Text breaks at soft wrap opportunities to stay within the container.
nowrap
This text will not wrap to the next line when it reaches the edge of the container. It overflows beyond the boundary instead.
container: 300px
Text overflows container
text-wrap-mode: wrap ! important Prevents wrapping. Text stays on a single line and overflows the container boundary.
