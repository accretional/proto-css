Ruby Overhang

ruby-overhang

auto

Ruby annotation may extend over adjacent text:
紅べに玉たまが転ころがる
ruby-overhang: spaces
Browser decides if ruby text can hang over adjacent content. Annotation may extend beyond the base character for better spacing.

none

Ruby annotation strictly stays within base:
紅べに玉たまが転ころがる
ruby-overhang: auto ! important
Ruby text does not overhang adjacent content. Annotation is strictly constrained to the width of the base character.
