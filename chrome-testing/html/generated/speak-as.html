Speak As AUDITORY

speak-as

This is an auditory CSS property used by screen readers. The visual demos below show how each value affects speech output.
auto
Default behavior - reads content naturally as words
text: Hello 2024!
♫
"Hello twenty twenty-four!"

speak-as: digits spell-out ! important

spell-out
Each character is spoken individually as a letter
text: Hello
♫
"H - E - L - L - O"

speak-as: normal ! important

digits
Numbers are spoken as individual digits
text: 2024
♫
"two - zero - two - four"

speak-as: spell-out literal-punctuation digits

literal-punctuation
Punctuation marks are spoken aloud by name
text: Hi, world!
♫
"Hi comma world exclamation-mark"

speak-as: digits spell-out
