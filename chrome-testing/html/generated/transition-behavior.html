Transition Behavior

transition-behavior

normal (default)
Discrete properties like display and visibility jump immediately without interpolation. No smooth transition occurs.
before
visible
➔
after
instant jump
transition-behavior: normal;
transition: opacity 0.5s, display 0.5s;
/* display jumps immediately, opacity ignored */
transition-behavior: normal ! important
allow-discrete
Allows discrete properties to participate in transitions. The property flips at the appropriate point during the transition duration.
before
visible
...
mid
fading
➔
after
hidden
transition-behavior: allow-discrete;
transition: opacity 0.5s, display 0.5s;
/* display flips at end, opacity fades smoothly */
transition-behavior: normal, normal
