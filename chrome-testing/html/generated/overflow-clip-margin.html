Overflow Clip Margin

overflow-clip-margin

Extends the clip boundary of an element with overflow: clip. The dotted line shows the effective clip region.

overflow-clip-margin: 0
overflow-clip-margin: border-box 0 ! important
overflow-clip-margin: +32mm
overflow-clip-margin: 0 padding-box ! important
overflow-clip-margin: content-box 7e82rex
