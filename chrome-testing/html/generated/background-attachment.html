Background Attachment

background-attachment

scroll
DEFAULT

Background scrolls with the page but not with the element's content.

Background is fixed relative to the element itself. When you scroll inside this box, the pattern stays put.
The checkerboard pattern moves with the page scroll, not the container scroll.
This is the default behavior for most elements.
Scroll down to see the effect on the background pattern positioning.
The background image scrolls when the page scrolls.
But it does not scroll when the element content scrolls.

background-attachment: scroll ! important, local ! important

fixed
VIEWPORT-LOCKED

Background is fixed to the viewport, creating a "window" effect.

Background is fixed relative to the viewport. It doesn't move when either the page or element scrolls.
Creates a parallax-like window effect where content slides over the background.
Commonly used for parallax scrolling designs.
Scroll down to see the content move over the fixed background.
The pattern stays perfectly still regardless of scroll position.
This creates an interesting depth illusion.

background-attachment: scroll ! important, local

local
CONTENT-LOCKED

Background scrolls with the element's content.

Background scrolls along with the element's content. It moves when you scroll inside this box.
The pattern is attached to the content flow, scrolling together with the text.
Useful for scrollable containers where the background should follow the content.
Scroll down and watch the checkerboard pattern move with this text.
The background position is relative to the content, not the element.
This value was added in CSS3 to give more control.

background-attachment: scroll ! important
