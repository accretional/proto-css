Mask Type

mask-type (SVG)

luminance

SVG mask

→

Result

mask-type: luminance ! important

Luminance (brightness) of the mask content determines visibility. White areas = visible, black areas = hidden, gray areas = semi-transparent. This is the default for SVG <mask> elements.

alpha

SVG mask

→

Result

mask-type: luminance ! important

Alpha (transparency) of the mask content determines visibility. Opaque pixels = visible, transparent pixels = hidden. Color of the mask content is ignored. Useful when mask content uses colored shapes.

mask-type applies to SVG <mask> elements. It determines whether the mask uses luminance values or alpha channel values to compute the final mask.
