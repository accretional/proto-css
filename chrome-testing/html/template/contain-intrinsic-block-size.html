Contain Intrinsic Block Size

contain-intrinsic-block-size

contain-intrinsic-block-size: none
No intrinsic block size hint. Element collapses when size-contained.
No size hint. Box collapses to zero height.
none (0)
contain-intrinsic-block-size: 100px
Fixed 100px block size hint for the element.
This element has an intrinsic block size of 100px. The browser uses this as the height when size containment is active.
100px
contain-intrinsic-block-size: 200px
Fixed 200px block size hint for the element.
A 200px intrinsic block size provides a taller placeholder. Useful for content-visibility: auto elements where you want to estimate the rendered height before layout.
200px
contain-intrinsic-block-size: auto 100px
Uses last rendered size, falling back to 100px.
The auto keyword remembers the last rendered size. If the element has not been rendered yet, 100px is used as the fallback.
auto 100px
contain-intrinsic-block-size: auto none
Uses last rendered size, falling back to none (zero).
Auto with none fallback. Uses last rendered size if available, otherwise collapses to zero height on first render.
auto none
