Position Try

position-try

The position-try shorthand combines position-try-order and position-try-fallbacks, defining how anchor-positioned elements try alternative positions when they overflow.

Button
Popup below
1st try: bottom
position-try: flip-block
tries below, then flips to above if no room
Button
Popup above
flipped: top
Popup below
position-try: flip-block
no room below, flipped to above
Button
Popup left
flipped: left
position-try: flip-inline
no room right, flipped to left
