Column Rule Width

column-rule-width

column-rule-width: thin
The thin keyword produces the thinnest possible rule. The exact width is browser-dependent but is typically 1px. Thin rules provide a subtle, minimal separation that does not distract from the content in the columns.
column-rule-width: medium
The medium keyword is the default width. It produces a moderately thick rule, typically around 3px. Medium rules are visible enough to clearly separate columns while remaining balanced and not overpowering the content.
column-rule-width: thick
The thick keyword creates the widest named rule, typically around 5px. Thick rules make a strong visual statement and clearly delineate column boundaries. They work well when the column gap is large enough to accommodate the width.
column-rule-width: 1px
A 1px rule is the finest precise width. This creates a hairline separator that is clear on high-density displays. Using explicit pixel values gives you exact control over the rule thickness rather than relying on browser-interpreted keywords.
column-rule-width: 5px
A 5px rule creates a bold, prominent divider. This width is highly visible and creates strong visual separation between columns. Wider rules can serve as decorative elements themselves, adding character to the multi-column layout design.
