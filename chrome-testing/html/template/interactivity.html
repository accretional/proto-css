Interactivity

interactivity

Experimental property. Similar to the HTML inert attribute but applied via CSS.

ACTIVE

Focusable Link

This text is selectable. All elements are interactive and respond to user input normally.

interactivity: auto

All elements remain interactive (default)

INERT

Non-focusable Link

This text is not selectable. All elements are inert and cannot be interacted with.

interactivity: inert

All elements become non-interactive, non-focusable, non-selectable
