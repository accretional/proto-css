Column Width

column-width

column-width: auto
With auto, the column width is determined by other properties like column-count. If no column-count is set either, all content remains in a single column. The browser has full control over column sizing.
Browser determines width automatically
column-width: 100px
Setting column-width to 100px creates narrow columns. The browser calculates how many 100px-wide columns fit in the container, then adjusts widths slightly to fill the space. This creates the most columns possible at approximately 100px each.
Target ~100px per column, many columns
column-width: 200px
A 200px column width creates comfortable reading columns. Each column holds a reasonable number of words per line. This width is a common sweet spot for multi-column article layouts where readability is the primary concern.
Target ~200px per column, moderate columns
column-width: 300px
Wide 300px columns hold significant content per line. Depending on container width, you may see only 2-3 columns at this setting. Wider columns are better for longer-form reading and complex content that benefits from more horizontal space.
Target ~300px per column, widest columns
column-width: min-content
With min-content, columns shrink to the minimum width needed by the content. Each column becomes as narrow as the longest unbreakable word or element inside it, creating very compact columns for dense layouts.
Columns as narrow as content allows
column-width: max-content
With max-content, columns expand to fit all content without wrapping. This typically results in a single wide column since max-content means the ideal width to display all content on one line without any line breaks.
Columns as wide as content prefers
