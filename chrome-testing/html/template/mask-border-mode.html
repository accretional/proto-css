The luminance value of each pixel in the mask image determines the masking level.

White = fully visible
Black = fully hidden
Gray = semi-transparent

The alpha channel of each pixel in the mask image determines the masking level.

Alpha 1 = fully visible
Alpha 0 = fully hidden
