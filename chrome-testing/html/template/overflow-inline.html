Overflow Inline

overflow-inline

Controls overflow in the inline direction (horizontal in horizontal writing modes).

overflow-inline: visible
Short text then a very long unbroken string that extends well beyond the container edge visibly
→ Inline overflow visible
overflow-inline: hidden
Short text then a very long unbroken string that extends well beyond the container edge but is hidden
→ Inline overflow hidden
overflow-inline: clip
Short text then a very long unbroken string that extends well beyond the container edge and is clipped
→ Inline overflow clip
overflow-inline: scroll
Short text then a very long unbroken string that extends well beyond and is scrollable horizontally
→ Inline overflow scrollable
overflow-inline: auto
Short text then a very long unbroken string that extends well beyond with auto scrollbar when needed
→ Inline overflow auto
