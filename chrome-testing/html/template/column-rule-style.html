Column Rule Style

column-rule-style

column-rule-style: solid
A solid rule creates a continuous, unbroken line between columns. This is the most common style for column separators and provides a clean, clear division. Solid rules work well for most layouts.
column-rule-style: dashed
Dashed rules create a series of rectangular dashes. The pattern of dashes and gaps adds a lighter visual weight compared to solid rules. Dashed style suggests a softer boundary between columns.
column-rule-style: dotted
Dotted rules display as a series of circular dots. This creates the lightest visual weight among the basic rule styles. Dotted rules are often used for decorative purposes or to indicate secondary boundaries.
column-rule-style: double
Double rules render two parallel lines with a gap between them. This style needs sufficient width to display both lines clearly. Double rules create a more formal, structured appearance.
column-rule-style: groove
Groove rules create a carved, 3D effect that appears inset into the surface. The appearance depends on the column-rule-color. Groove works best with wider rule widths where the dimensionality can be appreciated.
column-rule-style: ridge
Ridge rules are the opposite of groove, appearing to protrude from the surface. Like groove, the effect is more visible with wider rules. Ridge creates a raised, three-dimensional line between the columns.
