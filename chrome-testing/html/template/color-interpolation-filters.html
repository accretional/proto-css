Color Interpolation Filters

color-interpolation-filters

color-interpolation-filters: auto

Browser decides filter color space. Typically defaults to linearRGB for SVG filters.

color-interpolation-filters: sRGB

Filters computed in sRGB. Blur edges appear darker, matching how colors are stored in typical images.

color-interpolation-filters: linearRGB

Filters computed in linear RGB. Blur edges are brighter and more physically accurate, producing smoother transitions.
