Column Count

column-count

column-count: 1
With a single column, text flows naturally in one continuous block. This is the default behavior of most elements. The content fills the full width of the container without any column divisions or breaks.
column-count: 2
When column-count is set to 2, the text content is evenly distributed across two columns. This creates a newspaper-like layout that can improve readability for wider containers. The browser automatically balances content between the columns.
column-count: 3
With three columns, content is split into narrower sections. This layout works well for wider viewports where single-column text would create uncomfortably long line lengths. Each column receives roughly equal content distribution for balanced reading.
column-count: 4
Four columns create a dense, magazine-style layout. Content flows from left to right, top to bottom across all four columns. This is ideal for reference material or listings where compact presentation is desired and the viewport is wide enough.
