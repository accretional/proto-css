Column Fill

column-fill

column-fill: balance
Content is evenly distributed across all columns
The column-fill property controls how content is distributed across columns. With balance, the browser tries to equalize the height of content in each column. This creates a visually balanced layout where no single column is significantly taller than the others. Notice how the text is spread evenly across all three columns, creating a harmonious and symmetrical appearance. Each column ends at roughly the same vertical position, making the layout feel polished and intentional. This balanced distribution is the default behavior for most multi-column layouts.
column-fill: auto
Content fills columns sequentially, one at a time
With column-fill set to auto, content fills each column sequentially. The first column is filled completely from top to bottom before any content flows to the next column. This means columns may have very uneven heights. The last column may be shorter or even empty if there is not enough content to fill all columns. Notice how this text fills the first column fully, then the second column, creating a sequential flow pattern that differs visually from the balanced approach. The content stacks in order rather than being distributed evenly.
