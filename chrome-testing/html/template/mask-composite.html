Mask Composite

mask-composite

add (union)

mask-composite: add

Both mask shapes are combined. Union of both circles visible.

subtract

mask-composite: subtract

Second mask is subtracted from first. Only non-overlapping area of first shown.

intersect

mask-composite: intersect

Only the overlapping area of both masks is visible.

exclude (XOR)

mask-composite: exclude

Only non-overlapping areas visible. Overlap is hidden.

Each demo uses two overlapping circular radial-gradient masks offset left and right. The mask-composite value controls how they combine.
