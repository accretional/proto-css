View Transition Class

view-transition-class (experimental)

Grouping Elements by Class
Experimental
view-transition-class allows grouping multiple view transition elements under a shared class name, so you can style their transition pseudo-elements with a single rule instead of targeting each individually.
.card-1 {
  view-transition-name: card-1;
  view-transition-class: card;
}
.card-2 {
  view-transition-name: card-2;
  view-transition-class: card;
}

/* Style all cards at once */
::view-transition-group(.card) {
  animation-duration: 0.5s;
}

Multiple Classes
Experimental
Elements can have multiple view transition classes, allowing flexible styling combinations.
.hero {
  view-transition-name: hero;
  view-transition-class: animated fade-in;
}

/* Target by any class */
::view-transition-group(.animated) { ... }
::view-transition-group(.fade-in) { ... }
