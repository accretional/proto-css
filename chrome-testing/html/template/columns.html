Columns (Shorthand)

columns

columns: auto
column-width: auto | column-count: auto
The default value creates a single-column layout. Both column-width and column-count are set to auto, so the browser does not create multiple columns unless instructed by other properties.
columns: 2
column-width: auto | column-count: 2
Using a single integer sets the column-count. Here, two columns are created with automatic widths. The browser divides the available width equally among both columns for a simple two-column layout.
columns: 3 200px
column-width: 200px | column-count: 3
Providing both a count and width creates up to 3 columns, each at least 200px wide. The column-count acts as a maximum, while column-width acts as a minimum. If the container is too narrow, fewer columns are created.
columns: auto 300px
column-width: 300px | column-count: auto
Using a length with auto count sets the column-width. The browser calculates how many columns of approximately 300px width fit in the container. Column count is determined automatically based on available space.
