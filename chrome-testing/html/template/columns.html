Columns (Shorthand)

columns

columns: auto auto
column-width: auto | column-count: auto
The default value creates a single-column layout. Both column-width and column-count are set to auto, so the browser does not create multiple columns unless instructed by other properties.
columns: 3
column-width: auto | column-count: 3
Using a single integer sets the column-count. Here, three columns are created with automatic widths. The browser divides the available width equally among all three columns. This is the simplest way to create a multi-column layout.
columns: 200px
column-width: 200px | column-count: auto
Using a length value sets the column-width. The browser calculates how many columns of approximately 200px width fit in the container. Column count is determined automatically based on available space and the target width value provided.
columns: 150px 4
column-width: 150px | column-count: 4
Providing both a width and count creates up to 4 columns, each at least 150px wide. The column-count acts as a maximum, while column-width acts as a minimum. If the container is too narrow for 4 columns at 150px each, fewer columns are created.
columns: 100px 2
column-width: 100px | column-count: 2
Two columns with a 100px minimum width. Since the container is wide, both columns get much more than 100px. The width value serves as a floor, and the count limits the maximum number of columns created regardless of available space in the container.
columns: 250px 3
column-width: 250px | column-count: 3
Three columns targeting 250px each. The shorthand elegantly combines both constraints. If the container cannot accommodate three 250px columns, the browser reduces the count. This provides a responsive multi-column layout with a single property declaration.
