Column Span

column-span

column-span: none
Text flows normally across three columns. The highlighted element below stays within its column and does not break the column flow.
Stays in column
After the element, text continues to flow within the same column structure. The element is treated as regular content within the multi-column layout and does not span across column boundaries.
column-span: all
Text flows normally across three columns before reaching the spanning element below.
Spans all columns
After the spanning element, the remaining text resumes flowing in the multi-column layout. The spanning element breaks out of the column flow and stretches across all columns like a full-width banner.
