Text Wrap

text-wrap

This is a paragraph of text that will wrap normally across multiple lines within this container element.
text-wrap: wrap Standard line wrapping
This is a paragraph of text that will not wrap and will overflow the container instead.
text-wrap: nowrap No wrapping, overflows
This is a paragraph that uses balanced text wrapping for even line lengths.
text-wrap: balance Even line lengths
This is a paragraph that uses pretty text wrapping to avoid orphans and improve readability of the text block.
text-wrap: pretty Avoids orphans and widows
This is a paragraph that uses stable wrapping so editable content doesn't reflow from the start.
text-wrap: stable Lines before cursor don't reflow
