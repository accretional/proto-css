Timeline Scope

timeline-scope

Concept Experimental
/* Extend a named timeline to an ancestor */
.ancestor {
  timeline-scope: --my-scroll;
  animation-timeline: --my-scroll;
}

.descendant {
  scroll-timeline-name: --my-scroll;
}

Declares a timeline scope on an ancestor so descendant-defined scroll/view timelines can be referenced by elements outside the defining subtree.

timeline-scope: --my-scroll
Tree Structure
ancestor (timeline-scope: --tl)
|
sibling (animation-timeline: --tl)
|
container
  |
scroller (scroll-timeline: --tl)

Without timeline-scope on the ancestor, the sibling cannot reference --tl defined by the scroller, since it lives in a different subtree.

timeline-scope: none (default)
Multiple Timelines
/* Scope multiple timelines */
.root {
  timeline-scope:
    --scroll-tl,
    --view-tl;
}

/* Reset to default */
.element {
  timeline-scope: none;
}

Multiple named timelines can be scoped with a comma-separated list. Use none to reset.

timeline-scope: --a, --b
