Column Wrap

column-wrap

Experimental / Non-standard: column-wrap is not part of any current CSS specification. No browsers implement this property. The demos below illustrate the intended concept of controlling whether columns wrap or overflow.
Concept: column-wrap: nowrap
Columns do not wrap; overflow is clipped
When column-wrap would be set to nowrap, columns would not wrap to the next row. If column content exceeds the container height, it would be clipped or overflow. This is the conceptual default behavior where columns remain in a single horizontal row. Extra content that cannot fit within the constrained height would simply be hidden from view. Additional text continues to fill the columns but is cut off when the height limit is reached, demonstrating the nowrap concept clearly.
Content clipped at container boundary
Concept: column-wrap: wrap
Columns wrap to create new rows when needed
When column-wrap would be set to wrap, columns that exceed the container's height would create new rows of columns below. This is similar to how flex-wrap works for flex items. The content would continue flowing into a new set of columns positioned below the first row. This wrapping behavior would allow all content to remain visible without clipping, at the cost of increasing the overall container height as new column rows are created below the first set.
