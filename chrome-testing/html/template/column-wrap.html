Column Wrap

column-wrap

Experimental: column-wrap is not widely implemented. The demos below illustrate the intended concept of controlling whether columns wrap or overflow.
column-wrap: auto
Browser determines wrapping behavior
With auto, the browser decides whether columns should wrap based on available space and content. This is the default behavior where the user agent applies its own heuristics for column wrapping within the container.
Default browser behavior
column-wrap: nowrap
Columns do not wrap; overflow is clipped
When column-wrap is set to nowrap, columns do not wrap to the next row. If column content exceeds the container height, it is clipped or overflows. Columns remain in a single horizontal row regardless of content height.
Content clipped at boundary
column-wrap: wrap
Columns wrap to create new rows when needed
When column-wrap is set to wrap, columns that exceed the container height create new rows of columns below. This is similar to how flex-wrap works for flex items. Content continues flowing into new column rows positioned below the first set.
Content wraps into new rows
