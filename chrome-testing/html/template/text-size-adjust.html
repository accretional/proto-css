Text Size Adjust

text-size-adjust

auto
The browser may inflate text size on small screens. This is the default behavior that allows the text size inflation algorithm to run.
text-size-adjust: auto
none
The browser will not inflate text size. Text remains at the authored size regardless of viewport width or device orientation changes.
text-size-adjust: none
100%
Text size is explicitly set to 100% of the authored size. No inflation will occur, behaving similarly to none but expressed as a percentage.
text-size-adjust: 100%
150%
Text size adjust set to 150%. On mobile browsers that support inflation, text may be scaled up to 150% of the authored size to improve readability.
text-size-adjust: 150%
