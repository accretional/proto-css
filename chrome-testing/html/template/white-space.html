White Space

white-space

normal

This text has multiple spaces and a line break. It should collapse whitespace and wrap normally at the edge of the container.

white-space: normal

nowrap

This text has multiple spaces and a line break. It should collapse whitespace and never wrap to the next line.

white-space: nowrap

pre

This text has multiple spaces and a line break. It preserves whitespace and does not wrap.

white-space: pre

pre-wrap

This text has multiple spaces and a line break. It preserves whitespace and wraps at the edge.

white-space: pre-wrap

pre-line

This text has multiple spaces and a line break. It collapses spaces but preserves line breaks.

white-space: pre-line

break-spaces

This text has multiple spaces and a line break. It preserves whitespace and can break at spaces.

white-space: break-spaces
