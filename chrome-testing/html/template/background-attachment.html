Background Attachment

background-attachment

scroll
DEFAULT

Background scrolls with the page but not with the element's content.

Background is fixed relative to the element itself.
The pattern moves with page scroll, not container scroll.
This is the default behavior.
Scroll down to see the effect.
Background scrolls when the page scrolls.
But not when the element content scrolls.

background-attachment: scroll

fixed
VIEWPORT-LOCKED

Background is fixed to the viewport, creating a "window" effect.

Background fixed relative to the viewport.
Creates a parallax-like window effect.
Commonly used for parallax scrolling.
Scroll to see content move over background.
The pattern stays still regardless of scroll.
Creates depth illusion.

background-attachment: fixed

local
CONTENT-LOCKED

Background scrolls with the element's content.

Background scrolls with element content.
Pattern is attached to the content flow.
Useful for scrollable containers.
Background follows the content.
Position is relative to the content.
Added in CSS3 for more control.

background-attachment: local
