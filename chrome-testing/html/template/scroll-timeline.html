Scroll Timeline EXPERIMENTAL

scroll-timeline

Live Demo
Progress bar and box animate based on scroll position

scroll-timeline: --myScroll block

Shorthand Syntax
scroll-timeline combines name and axis in one declaration
scroll-timeline:
--name
axis
Longhand equivalents:
/* Shorthand */
scroll-timeline: --myScroll block;

/* Equivalent longhands */
scroll-timeline-name: --myScroll;
scroll-timeline-axis: block;
More examples:
scroll-timeline: --hero inline;
scroll-timeline: --sidebar y;
scroll-timeline: --page block;
scroll-timeline: none;

scroll-timeline: <name> <axis>
