none (default)
No scroll timeline is established for the element
✕
No timeline created.
Animations cannot reference this scroller.

scroll-timeline-name: none

Usage Pattern
/* Define the timeline */
.scroller {
  overflow-y: scroll;
  scroll-timeline-name: --page-progress;
}

/* Use it in animation */
.animated {
  animation: fade-in linear;
  animation-timeline: --page-progress;
}
