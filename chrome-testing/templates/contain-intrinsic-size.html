Contain Intrinsic Size (Shorthand)

contain-intrinsic-size

contain-intrinsic-size: none
width: none | height: none
No size hint. Element collapses to zero in both dimensions when size-contained.
W: 0
H: 0
contain-intrinsic-size: 100px
width: 100px | height: 100px
Single value sets both width and height to 100px. A square placeholder.
W: 100px
H: 100px
contain-intrinsic-size: 200px
width: 200px | height: 200px
A larger 200px square placeholder. Good for image containers or card components where you know the approximate rendered size.
W: 200px
H: 200px
contain-intrinsic-size: 300px 150px
width: 300px | height: 150px
Two values set width and height independently. This creates a landscape-oriented placeholder.
W: 300px
H: 150px
contain-intrinsic-size: auto 100px
Remembers last size, fallback 100px
Auto remembers last rendered size. Falls back to 100px on first render. Best for content-visibility: auto.
W: auto/100px
H: auto/100px
