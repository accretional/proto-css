mask-mode: luminance

The brightness (luminance) of the mask image determines visibility. White = visible, black = hidden.

mask-mode: alpha

The alpha channel of the mask image determines visibility. Opaque = visible, transparent = hidden.

mask-mode: match-source

Uses luminance for SVG <mask> elements and alpha for CSS gradient/image masks. Default value.
