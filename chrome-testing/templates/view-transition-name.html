View Transition Name

view-transition-name (experimental)

none (default)
default
The element does not participate in view transitions. It will not be individually animated during page transitions; instead it cross-fades with the rest of the page.
.element {
  view-transition-name: none;
  /* Element transitions with full page cross-fade */
}

Custom Name
Experimental
Assigns a unique name enabling the element to animate independently during view transitions. Elements with matching names on different pages morph into each other.
.hero-image {
  view-transition-name: hero;
  /* Element transitions independently */
}

/* Style the transition pseudo-elements */
::view-transition-old(hero) { animation: fadeOut 0.3s; }
::view-transition-new(hero) { animation: fadeIn 0.3s; }
