User Modify

-webkit-user-modify (non-standard)

read-only
Not editable
Content cannot be modified by the user. This is the default behavior for most elements.
This text is read-only. Users cannot edit this content. The element behaves like a normal, non-editable element.
-webkit-user-modify: read-only
read-write
Rich text editable
Content is editable with rich text support (bold, italic, etc.) similar to contenteditable.
This text is editable with rich text formatting. Users can type, paste HTML, and format text.
-webkit-user-modify: read-write
read-write-plaintext-only
Plain text editable only
Content is editable, but only plain text input is allowed. No rich text formatting can be applied.
This text is editable as plain text only. No bold, italic, or other formatting is allowed. Only raw text input.
-webkit-user-modify: read-write-plaintext-only
