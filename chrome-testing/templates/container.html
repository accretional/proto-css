Container (Shorthand)

container

container: sidebar / inline-size
name: sidebar | type: inline-size
sidebar
Sidebar Container
This container is named "sidebar" with inline-size containment. @container sidebar queries respond to its inline dimension changes.
container: main / size
name: main | type: size
main
Main Container
Named "main" with full size containment. Responds to both inline and block dimension queries. More restrictive than inline-size.
container: card / inline-size
name: card | type: inline-size
card
Card Container
Named "card" with inline-size type. Each card component can independently respond to its own width via @container card queries.
container: panel / normal
name: panel | type: normal
panel
Panel Container
Named "panel" with normal type. This establishes a named container but without size containment, so dimensional @container queries will not work.
