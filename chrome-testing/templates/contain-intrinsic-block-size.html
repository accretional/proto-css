Contain Intrinsic Block Size

contain-intrinsic-block-size

contain-intrinsic-block-size: none
No intrinsic block size hint. Element collapses when size-contained.
No intrinsic size hint provided. The element has zero height when size-contained with no explicit height set.
none (0)
contain-intrinsic-block-size: 80px
Fixed 80px block size hint for the element.
This element has an intrinsic block size of 80px. The browser uses this as the height when size containment is active, preventing layout shift.
80px
contain-intrinsic-block-size: 150px
Fixed 150px block size hint for the element.
A 150px intrinsic block size provides a taller placeholder. This is useful for content-visibility: auto elements where you want to estimate the rendered height before the content is actually laid out by the browser.
150px
contain-intrinsic-block-size: auto 120px
Uses last rendered size, falling back to 120px.
The auto keyword remembers the last rendered size. If the element has not been rendered yet, 120px is used as the fallback. This provides the best user experience for dynamic content.
auto 120px
